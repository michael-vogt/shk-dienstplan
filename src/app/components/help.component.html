Hilfe

Kurzanleitung zur Bedienung. Abschnitte lassen sich einzeln auf- und zuklappen.

Überblick

Mit dieser App wird jeweils ein Dienstplan geplant: entweder ein Semesterplan oder ein Ferienplan. Welcher Typ aktiv ist, wird in Schritt 1 festgelegt.

  • Semesterplan — eine Musterwoche ohne Datumsbezug, wiederkehrend gültig für jede Woche des Semesters.
  • Ferienplan — für jede Kalenderwoche im gewählten Zeitraum wird einzeln geplant, mit echten Terminen.

Die Daten beider Typen bleiben beim Wechsel erhalten; die App zeigt immer nur einen davon gleichzeitig.

Schritt 1 — Plantyp und Öffnungszeiten

Die beiden Kacheln oben wechseln zwischen Semester- und Ferienplan. Beim Ferienplan erscheint zusätzlich ein Zeitraum (von/bis), aus dem sich die einzelnen Kalenderwochen automatisch ergeben.

Für jeden Wochentag lässt sich festlegen, ob geöffnet ist sowie Start- und Endstunde. „Auf alle Tage übertragen" überträgt die Zeiten eines Tages auf alle anderen.

Die Öffnungszeiten gelten in beiden Plantypen gleich und für alle Wochen. Einzelne abweichende Termine (Feiertage o. Ä.) werden nicht gesondert erfasst.

Schritt 2 — Verfügungszeiten

Namen im Feld oben eintragen und mit „Hinzufügen" oder Enter bestätigen. Jede Hilfskraft erscheint danach als farbiger Reiter.

Ein Klick auf eine Stunde im Raster der ausgewählten Person wechselt den Zustand im Kreis:

Ja Kann in dieser Stunde arbeiten
Wenn es sein muss Geht zur Not, keine erste Wahl
Nein Nicht verfügbar — Zuweisung wird als Fehler markiert
Noch offen Noch keine Antwort eingetragen
Urlaub Blockiert die Zuweisung vollständig (nur Ferienplan)

„alle Ja" am Spaltenkopf setzt einen ganzen Tag auf einmal, die Knöpfe „Ganze Woche" die komplette Woche.

Im Ferienplan: mehrere Wochen

Zwei Werkzeuge erleichtern das Ausfüllen über mehrere Wochen hinweg:

  • „Angaben übernehmen aus" — überträgt die Zeiten einer einzelnen gewählten Woche auf die aktuell angezeigte.
  • „Diese Woche auf alle N anderen übertragen" — überträgt die aktuell angezeigte Woche auf sämtliche übrigen. Bestehende Antworten dort werden überschrieben, deshalb erst nach einer Sicherheitsabfrage.

Wochenübersicht

Unterhalb der Bearbeitungstabelle zeigt eine zweite, kompakte Tabelle je Stunde, wie viele Hilfskräfte insgesamt mit „Ja" oder „Wenn es sein muss" geantwortet haben — unabhängig davon, welche Person gerade bearbeitet wird. Rot markiert eine Stunde ohne jede Verfügbarkeit, Gelb eine mit nur einer Person, Grün ab zwei Personen.

Urlaub (nur Ferienplan)

Im Abschnitt „Urlaub" lässt sich für die ausgewählte Person ein Zeitraum eintragen. Ein Klick auf einen Tag oben in der Kopfzeile übernimmt dessen Datum als Startdatum; bleibt das Enddatum leer, gilt der Urlaub für die ganze angezeigte Woche.

Urlaub ist eine echte Sperre: Für diese Tage lässt sich die Person im Dienstplan nicht einteilen. Bereits geplante Stunden in diesem Zeitraum werden beim Eintragen automatisch entfernt.

Schritt 3 — Dienstplan

Ein Klick auf eine Stunde zeigt rechts die passenden Kandidaten, sortiert nach Verfügbarkeit. Ein Klick auf einen Namen teilt die Person zu oder entfernt sie. Mehrere Personen können derselben Stunde zugewiesen werden, auch mit überlappenden Zeiten.

Blöcke

Umschalt + Klick markiert eine zusammenhängende Reihe von Stunden desselben Tages (ein Block bleibt immer innerhalb eines Tages). Umschalt + Pfeil hoch/runter verlängert den Block ohne Maus. Ein Klick auf einen Namen besetzt dann den ganzen Block; ist er teilweise besetzt, wird er aufgefüllt statt geleert.

Ziehen und Ablegen

Namen lassen sich aus der Liste rechts oder direkt aus einer besetzten Stunde ziehen. Ziehen aus einer Stunde verschiebt die Person; mit gedrückter Strg-Taste wird stattdessen kopiert. Eine ganze gezogene Schicht behält beim Ablegen ihre Länge und den angefassten Griffpunkt bei.

Nach einer Verschiebung erscheint kurz „Verschoben — Rückgängig". Das betrifft nur diesen einen Schritt und verschwindet bei der nächsten Änderung oder einem Wochenwechsel.

Theke oder Büro

Grundsätzlich arbeiten Hilfskräfte an der Ausleihtheke. Auf jeder eingeteilten Plakette lässt sich per Klick auf „Theke" / „Büro" kennzeichnen, dass diese eine Person für genau diese eine Stunde stattdessen im Büro eingeteilt ist.

Hinweise

Unten listet die App alle Auffälligkeiten der angezeigten Woche: unbesetzte Stunden, Zuweisungen entgegen einer „Nein"-Antwort oder ohne Antwort, sowie nur mit „Wenn es sein muss" besetzte Stunden. Diese Hinweise blockieren nichts, sie weisen nur darauf hin.

Im Ferienplan: Wochen kopieren

„Einteilung übernehmen aus" überträgt die Besetzung einer Woche auf die aktuell angezeigte. „Zur laufenden Woche" springt zur Kalenderwoche, in der heute liegt.

Daten sichern

Alle Eingaben werden fortlaufend automatisch gespeichert — es gibt keinen separaten Speichern-Knopf. Für die Datenhaltung stehen zwei Wege zur Verfügung:

  • Im Browser (Standard) — die Daten liegen lokal auf diesem Gerät.
  • Mit einer Datei verknüpft (Chrome, Edge, Opera) — über „Mit Datei verknüpfen" oben in der Kopfzeile lässt sich eine eigene Datei wählen, in die jede Änderung automatisch geschrieben wird, etwa auf einem gemeinsam genutzten Laufwerk. In Firefox und Safari steht das nicht zur Verfügung.

„Dienstplan als CSV" und „Verfügungszeiten als CSV" exportieren beide Tabellen für Excel. „Daten sichern" erzeugt eine vollständige Sicherungsdatei, die sich über „Daten laden" auf einem anderen Rechner wieder einspielen lässt.

Die App sendet zu keinem Zeitpunkt Daten über das Netzwerk — alle Daten bleiben ausschließlich lokal, egal ob im Browser oder in einer verknüpften Datei.

Drucken

Strg+P druckt den Dienstplan. Gedruckt werden alle Wochenpläne, je einer pro Seite im Querformat, ohne Bedienelemente und ohne die Hinweisliste — im Semesterplan ergibt das genau eine Seite.
